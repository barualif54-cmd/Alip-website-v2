Sedikit cerita tentang saya

Saya belajar dan membangun proyek langsung dari perangkat Android pakai Termux — dari situ kebiasaan coding di lingkungan terbatas jadi tantangan tersendiri yang saya nikmati.

Sebagian besar waktu saya habis buat ngembangin ekosistem bot Telegram: mulai dari bot manajemen grup, sampai dashboard admin berbasis web yang realtime.

Saya suka eksplorasi hal baru — dari nyobain desktop Linux penuh di atas Termux, sampai eksperimen tampilan terminal ala hacker-aesthetic.

Ke depannya, saya pengen terus ningkatin kualitas proyek-proyek ini biar makin stabil dan enak dipakai.
